## Structure

- **Organization Overview** – high‑level purpose and ecosystem description (`ORGANIZATION_OVERVIEW.md`).
- **Governance** – policies, decision registers and standards.
- **Architecture** – ecosystem, shared data and integration diagrams.
- **Projects** – individual profiles for each of the six repositories.
- **Onboarding** – guides for new contributors.
- **Reports** – status and checkpoint documents.

This file defines the logical layout used throughout the repository.
