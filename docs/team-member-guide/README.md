## Important interpretation
This guide is detailed orientation, not proof that every described capability is built. It separates intended scope, known decisions, candidate work breakdown, reported progress, and evidence still required. Unknowns are marked rather than invented.

The organization repository governs cross-project context and policies. Each project repository is authoritative for current code, technical implementation, tests, deployment, and release evidence. If this summary conflicts with current project evidence, ask the project owner.
