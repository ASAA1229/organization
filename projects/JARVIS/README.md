# JARVIS Project Profile

## Purpose
The JARVIS repository provides the voice‑enabled assistant UI and backend services that integrate with the shared ecosystem.

## Responsibilities
- Natural‑language processing and intent routing.
- UI components for web and desktop.
- Event publishing to the shared event bus.

## Current State
- ~61 % complete. Core voice pipeline functional; UI integration pending.

## Relationships
- Auth via Configuration/Keycloak.
- Consumes shared APIs from the backend gateway.
- Publishes events consumed by Portfolio and ASAA.
