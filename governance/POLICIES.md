# Policies

- **Branch protection** – all repos use the `new` branch as the primary development branch; protection rules are disabled per organization policy.
- **Commit signing** – GPG signing is optional but recommended.
- **Code review** – at least one reviewer for non‑trivial changes.
- **Security** – all secrets stored in environment variables; no hard‑coded credentials.
